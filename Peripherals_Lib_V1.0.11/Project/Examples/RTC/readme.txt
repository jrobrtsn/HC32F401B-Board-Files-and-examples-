功能描述：
此样例演示RTC计时功能，需外接32.768KHZ晶振(PC14和PC15)，每秒产生一次中断。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
实验步骤：
1. 编译下载程序；
2. 示波器测 PA9每秒翻转一次。
