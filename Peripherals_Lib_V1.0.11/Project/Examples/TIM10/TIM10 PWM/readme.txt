功能描述：
此样例演示TIM10输出PWM功能(频率可修改，占空比固定50%)

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
实验步骤：
1. 编译下载程序；
2. 示波器测PC0和PC1为反向输出500HZ方波、PA8引脚输出500HZ方波。
