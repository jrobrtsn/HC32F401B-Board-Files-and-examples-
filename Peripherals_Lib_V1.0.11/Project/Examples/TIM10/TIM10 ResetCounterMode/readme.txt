================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示TIM10内部触发和外部触发复位计数器功能。
内部触发复位计数器: 当ExternalResetSoure=0时，TIM1作为触发信号(125us)，当TIM1触发中断时就会重置TIM10.CNT从0开始计数，
				    PA9、PA8每125us翻转一次。
外部触发复位计数器: 当ExternalResetSoure=1时，外部ETR(PC2)引脚作为触发源，外部给PC2高电平则会重置TIM10.CNT从0开始计数,
				    A8每500us翻转一次。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
实验步骤：
1. 编译下载程序；
2. 用示波器测PA8、PA9。
