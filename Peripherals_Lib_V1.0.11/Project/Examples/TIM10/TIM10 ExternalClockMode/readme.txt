                                样例使用说明

================================================================================
功能描述：
此样例演示TIM10内部计数和外部计数功能
内部计数模式: ExternalClock=0时，TIM1的输出上升沿作为TIM10的计数时钟，在TRGI上升沿计数器自增1，
			  A9每500us翻转一次，PA8每9ms翻转一次。
外部计数模式: ExternalClock=1时，TIM10的计数时钟源切换为外部ETR引脚的信号，在ETR上升沿计数器自增1，
			  外部给PC2高电平计数器加1，计数9次产生溢出，PA8翻转。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
实验步骤：
1. 编译下载程序；
2. 示波器测PA8、PA9。
