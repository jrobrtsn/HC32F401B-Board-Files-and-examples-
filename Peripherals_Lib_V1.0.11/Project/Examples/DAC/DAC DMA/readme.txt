================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了DAC配合DMA和EXTI实现自动循环波形输出。DMA以循环模式将内存数组
TX_BUFF[]的4个数据搬运到DAC数据寄存器，每次EXTI9(PA9)下降沿触发一次DAC转换
并启动DMA搬运下一个数据。DMA完成4个数据搬运后触发TC中断，自动循环回到数组
开头。主循环中PC10持续Toggle指示程序运行状态。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化、GPIO初始化、EXTI初始化、DMA初始化、DAC初始化
3. PC10持续Toggle，指示程序正常运行
4. 给PA9引脚输入下降沿触发信号，每次下降沿触发一次DAC转换+DMA搬运
5. DMA循环搬运TX_BUFF[4] = {0x10, 0x100, 0x200, 0x300}到DAC
6. 用示波器观察PA4/PA8的DAC输出波形（阶梯波）

================================================================================
注意事项：
1. TX_BUFF[4] = {0x10, 0x100, 0x200, 0x300}，对应输出电压约18.75mV, 300mV, 600mV, 900mV（Vref=1.2V）
2. DAC DMA触发源配置为EXTI9，即PA9下降沿触发DAC转换和DMA请求
3. DMA配置为循环模式(Circular)，4个数据搬运完成后自动回到TX_BUFF[0]重新开始
4. DMA通道为DMA1_Stream0_Channel2，数据宽度为字(32位)
5. 需通过SYSCFG->OUTSEL配置DAC输出引脚映射，并通过SYSCFG_EXTILineConfig映射PA9到EXTI Line9
