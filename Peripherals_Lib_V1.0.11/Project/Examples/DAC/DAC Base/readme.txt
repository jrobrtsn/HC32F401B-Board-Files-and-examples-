================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了DAC的基本使用，输出固定的模拟电压值。DAC输出引脚为PA4/PA8，
参考电压为内部1.2V基准源，输出数据值0x200(512)，对应输出电压约0.6V。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化、GPIO初始化（PA4/PA8模拟模式）、DAC初始化
3. DAC配置为输出使能，参考电压选择内部1.2V基准
4. 写入固定数据值0x200(512)到DAC数据寄存器
5. 用万用表或示波器测量PA4(PA8)引脚的输出电压

================================================================================
注意事项：
1. DAC分辨率为10位（0~1023），输出电压计算公式：Vout = DAC数据 / 1024 × 1.2V
2. 需通过SYSCFG->OUTSEL寄存器配置DAC输出引脚映射（OUTSEL=0 → PA4  OUTSEL=1 → PA8）
3. DAC挂在APB1总线上，初始化前需使能RCC_APB1Periph_DAC时钟
