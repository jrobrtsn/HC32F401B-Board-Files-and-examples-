================================================================================
                                样例使用说明

================================================================================
工程概述：
此样例演示了独立看门狗(IWDG, Independent Watchdog)的功能。
IWDG基于LSI内部低速RC振荡器(约40kHz)独立运行，与系统时钟完全隔离。
即使系统主时钟停止，IWDG仍能正常工作并检测系统故障。
上电后PA0翻转20次作为启动指示，随后进入死循环。
在死循环中通过PA1按键(低电平)手动喂狗(重载计数器)，
若超过约819ms未喂狗，IWDG将触发系统复位。

================================================================================
硬件连接：
  PA0 = 推挽输出(启动/复位指示，翻转可见)
  PA1 = 上拉输入(按键，低电平有效，按下=喂狗)

  简易测试接线: PA0 → LED(观察翻转)，PA1 → 按键(接地)

================================================================================
软件配置：
  IDE环境:     MDK 5.36.0.0 / IAR 8.20.2
  芯片型号:    HC32F401系列
  系统时钟:    168MHz (HSE → PLL)
  看门狗时钟:  LSI(约40kHz)，独立于系统时钟

================================================================================
IWDG参数配置与计算：

【IWDG 独立看门狗】
  - 时钟源:    LSI内部低速RC振荡器(约40kHz)
  - 超时公式:  Tout = (4 × 2^prv) / f_lsi × rlv  (ms)
               prv = 预分频器寄存器值(PR[2:0])
               rlv = 重装载寄存器值(RL[11:0]), 范围 0x000~0xFFF (0~4095)
               f_lsi = LSI实际频率(kHz), 标称40kHz, 实测约29.4kHz

  prv与分频系数对照:
    prv=0: 4×2^0=4  → IWDG_Prescaler_4     prv=1: 4×2^1=8  → IWDG_Prescaler_8  (当前)
    prv=2: 4×2^2=16 → IWDG_Prescaler_16    prv=3: 4×2^3=32 → IWDG_Prescaler_32
    prv=4: 4×2^4=64 → IWDG_Prescaler_64    prv=5: 4×2^5=128→ IWDG_Prescaler_128
    prv=6: 4×2^6=256→ IWDG_Prescaler_256

  当前配置: prv=1, rlv=0x0FFF(4095)
  - 计数时钟:  LSI / (4×2^1) = f_lsi / 8
  - 理论值:    Tout = 8 / 40 × 4095 ≈ 819ms   (f_lsi=40kHz, 标称)
  - 实测值:    Tout = 8 / 29.4 × 4095 ≈ 1113ms ≈ 1.113s (f_lsi≈29.4kHz)
  - 注意:      LSI精度约±30%, 实际超时以实测为准, 不可用于精确定时

  各prv在rlv=4095时的超时时间(按标称40kHz / 实测29.4kHz):
    prv=0 (÷4):    Tout = 4/40×4095≈410ms  / 4/29.4×4095≈557ms
    prv=1 (÷8):    Tout = 8/40×4095≈819ms  / 8/29.4×4095≈1113ms (当前)
    prv=2 (÷16):   Tout = 16/40×4095≈1.64s / 16/29.4×4095≈2.23s
    prv=3 (÷32):   Tout = 32/40×4095≈3.28s / 32/29.4×4095≈4.46s
    prv=4 (÷64):   Tout = 64/40×4095≈6.55s / 64/29.4×4095≈8.92s
    prv=5 (÷128):  Tout = 128/40×4095≈13.1s/ 128/29.4×4095≈17.83s
    prv=6 (÷256):  Tout = 256/40×4095≈26.2s/ 256/29.4×4095≈35.66s

================================================================================
工作原理：
1. 系统上电后，配置系统时钟(168MHz)和各外设
2. IWDG配置完成后立即使能，开始以5kHz频率递减计数
3. PA0翻转20次作为启动指示(若为复位重启则重新翻转)
4. 主循环死循环检测PA1按键:
   - 若PA1=低电平 → 调用IWDG_ReloadCounter()喂狗 → 计数器回到4095
   - 若PA1=高电平 → 不喂狗 → 计数器持续递减
5. 计数器减到0 → IWDG超时 → 触发系统复位 → 程序重新执行
6. 可在调试器中观察PA0翻转来确认复位是否发生

================================================================================
使用步骤：
1. 打开工程
2. 编译并下载到目标芯片
3. 观察PA0: 上电后翻转20次，然后停止
4. 不按PA1 → 约0.8秒后芯片自动复位 → PA0重新翻转20次
5. 持续按住PA1 → 芯片不复位(持续喂狗)
6. 可通过示波器观察PA0波形，测量两次复位之间的时间间隔

================================================================================
运行结果：
  - 上电: PA0翻转20次
  - 不喂狗: 约819ms后系统复位 → PA0再次翻转20次
  - 持续喂狗(按住PA1): 系统持续运行，不复位
  - 喂狗后释放再按下: 计数器被重置，从释放到超时约819ms

================================================================================
注意事项：
1. IWDG使用独立LSI时钟(~40kHz)，不受系统时钟影响
2. LSI精度较低(约±30%)，实际超时时间有较大偏差，不可用于精确定时
3. IWDG一旦使能无法软件关闭，只能由系统复位或上电复位清除
4. 调试时若调试器暂停CPU，IWDG仍继续计数，可能导致意外复位
5. 实际应用中应在主循环或定时中断中定期喂狗
6. 修改预分频或重载值前必须先调用IWDG_WriteAccessCmd(Enable)解锁
7. 喂狗间隔应远小于超时时间，一般取超时时间的30%~50%
