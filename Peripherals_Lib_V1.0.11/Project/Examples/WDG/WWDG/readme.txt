================================================================================
                                样例使用说明

================================================================================
工程概述：
此样例演示了窗口看门狗(WWDG, Window Watchdog)的功能。
WWDG是一个7位递减计数器(范围0x7F~0x3F)，基于PCLK1时钟(42MHz)运行。
与IWDG不同，WWDG要求在特定的"时间窗口"内喂狗：
- 喂得太早(计数器值>窗口上限0x5F) → 触发复位
- 喂得太晚(计数器值<窗口下限0x3F) → 触发复位
- 只能在窗口内喂狗: 0x5F ≥ 计数器 ≥ 0x40

本样例利用WWDG的提前警告中断(EWI)，在计数器降至0x40时
自动重载计数器并翻转PA0，实现精确的周期性窗口喂狗。

================================================================================
硬件连接：
  PA0 = 推挽输出(喂狗指示LED，每次喂狗翻转一次，约6.14ms周期)

  简易测试: PA0 → LED(观察约6.14ms周期的闪烁)

================================================================================
软件配置：
  IDE环境:     MDK 5.36.0.0 / IAR 8.20.2
  芯片型号:    HC32F401系列
  系统时钟:    168MHz (HSE → PLL)
  PCLK1时钟:   42MHz (HCLK / 4，WWDG时钟来源)
  WWDG时钟:    42MHz / 4096 / 1 ≈ 10.25kHz

================================================================================
使用步骤：
1. 打开工程
2. 编译并下载到目标芯片
3. 观察PA0: 约6.14ms周期翻转(频闪速度快，建议用示波器观察)
4. 若PA0持续翻转 → WWDG窗口喂狗正常工作
5. 若PA0停止翻转 → WWDG可能因时序异常触发复位
6. 修改预分频值可调节翻转周期，观察PA0频率变化

================================================================================
运行结果：
  - PA0周期: ≈ 6.14ms (频率≈163Hz)
  - 每次EWI中断完成一次喂狗
  - 系统不会触发WWDG复位(正常喂狗)

  若需要观察WWDG复位效果，可修改代码:
    - 在WWDG_IRQHandler中去掉WWDG_SetCounter(0x7F) → 约97.5μs后复位
    - 在main()中过早调用WWDG_SetCounter(0x7F) → 立即复位(喂太早)

================================================================================
注意事项：
1. WWDG使用PCLK1时钟(经4096固定分频+预分频)，时序精确可控
2. 窗口上限(WINDOW)决定最早喂狗时间：在计数器小于窗口值之前喂狗会复位
3. 窗口下限(0x3F)为硬件固定值，决定最晚喂狗时间
4. EWI提前警告中断在0x40触发，距复位仅1个计数(约97.5μs)，需及时响应
5. 与IWDG不同，WWDG可以软件使能和关闭(复位后)
6. 在调试中若暂停CPU，WWDG计数器会继续运行，可能意外触发复位
7. WWDG非常适合需要精确时序监控的应用场景(如任务周期检测)
8. 修改窗口值可调整"不可喂狗区"的宽度，增强系统鲁棒性

================================================================================
IWDG与WWDG对比：
  特性        IWDG                     WWDG
  ────────    ─────────────────────    
  时钟源      LSI(~40kHz, 独立)        PCLK1(42MHz, 系统)
  计数范围    12位(0~4095)             7位(0x7F~0x3F)
  喂狗时机    任意时刻(超时前)          窗口内(不能太早或太晚)
  中断支持    无                        有(EWI提前警告)
  精度        低(LSI≈±30%)             高(PCLK精确)
  是否可以关闭 否(使能后不可关)         是(复位后可重新配置)
  适用场景    系统崩溃检测              任务时序监控
