================================================================================
                                样例使用说明

================================================================================
工程概述：
此样例演示了通用定时器(TIM1)的输入捕获(Input Capture)功能。
TIM1的CC1通道捕获外部PWM信号的上升沿，CC2通道捕获下降沿，
在中断中自动计算信号周期和高电平时间，可用于频率和占空比测量。
同时TIM4_CH1(PA4)输出一路100kHz/50%占空比的参考PWM信号，
方便用户通过跳线将PWM输出直接接入捕获引脚进行闭环测试。

================================================================================
硬件连接：
- 默认使用TIM1 (TIM_No_TEST=1，在main.h中配置)
- 捕获引脚:  PA2 = TIM1_CH1 (上升沿捕获)
             PA3 = TIM1_CH2 (下降沿捕获)
- PWM输出:   PA4 = TIM4_CH1 (100kHz, 50%占空比)
- 运行指示:  PA0 = 推挽输出(翻转指示程序运行)

各TIM通道可选引脚映射(修改main.h中TIM_No_TEST宏):
  TIM1:  PA2/PA3   TIM2: PA11/PA12  TIM3: PA1/PA2
  TIM4:  PA4/PA5   TIM5: PA7/PA8    TIM6: PB14/PB15
  TIM7:  PA8/PA9   TIM8: PC10/PC12  TIM9: PB7/PB8

简易闭环测试接线: PA4(输出) ---> PA2(捕获输入)

================================================================================
软件配置：
- IDE环境:     MDK 5.36.0.0 / IAR 8.20.2

================================================================================
定时器参数与计算公式：

【TIM1 输入捕获】
- 预分频:    168-1 → 计数频率 = 168MHz / 168 = 1MHz (1us/计数)
- 自动重载:  0xFFFF (65535)
- 最大测量周期: 65535 × 1us ≈ 65.5ms
- 最小测量频率: 1000000 / 65535 ≈ 15.3Hz
- 频率计算:    频率(Hz) = 1000000 / capture_period
- 占空比计算:  占空比(%) = capture_high_time × 100 / capture_period

【TIM4 PWM输出】
- 预分频:    84-1 → 计数频率 = 84MHz / 84 = 1MHz
- 重载值:    10-1 → PWM频率 = 1MHz / 10 = 100kHz (周期=10us)
- 脉宽值:    5 → 占空比 = 5 / 10 = 50%
- 高电平时间: 10us × 50% = 5us

================================================================================
工作原理：
1. 系统上电后，TIM4_CH1(PA4)持续输出100kHz/50% PWM信号
2. TIM1配置为向上计数模式，计数频率1MHz
3. CC1通道检测上升沿：硬件自动将当前计数值锁存到CCR1
4. CC2通道检测下降沿：硬件自动将当前计数值锁存到CCR2
5. 每次CC1捕获事件触发中断，在中断中:
   - 读取当前上升沿时刻(current_cc1)
   - 计算周期 = 当前上升沿 - 上一次上升沿
   - 更新capture_timer[0]为本次上升沿时刻
   - 设置capture_flag通知主循环
6. 每次CC2捕获事件触发中断，在中断中:
   - 读取下降沿时刻存入capture_timer[1]
   - 计算高电平时间 = 下降沿时刻 - 最近一次上升沿时刻

    波形示意:
    高  +------+     +------+     +------
        |      |     |      |     |
    低  +      +-----+      +-----+
        ^      ^     ^      ^
       CC1    CC2   CC1    CC2
        ^      ^
        |--高--|     period = CC1(本次) - CC1(上次)
        |<----- 周期 ------>|

================================================================================
使用步骤：
1. 打开工程(MDK: MDK\Project.uvprojx 或 IAR: IAR\TEST.eww)
2. 在main.h中确认TIM_No_TEST宏为需要使用的TIM通道(默认=1)
3. 编译工程并下载到目标芯片
4. 连接捕获引脚到待测信号(或用跳线将PA4连接到PA2做闭环测试)
5. 在调试器中设置断点于TIM_IRQHandler()，观察变量:
   - capture_timer[0]: CC1上升沿时刻
   - capture_timer[1]: CC2下降沿时刻
   - capture_period:   信号周期(单位: us)
   - capture_high_time:高电平时间(单位: us)
   - capture_flag:     周期捕获完成标志
6. 观察PA0引脚电平翻转(示波器/逻辑分析仪)，确认程序正常运行
7. 观察PA4引脚PWM输出波形(示波器)，验证100kHz/50%占空比

================================================================================
运行结果：
以PA4输出(100kHz PWM)接入PA2捕获输入为例:
  - TIM1计数频率 = 1MHz (1us/count)
  - PWM周期 = 10us → 捕获周期值 ≈ 10
  - PWM高电平 = 5us → 高电平计数值 ≈ 5
  - 占空比 = 5/10 = 50%

实际捕获值可能存在±1个计数的误差(量化误差)，
以及由时钟同步引起的采样抖动。

================================================================================
注意事项：
1. 捕获值反映从计数器启动到捕获事件发生的时钟周期数
2. CC1和CC2可分别捕获不同引脚或同一引脚的不同边沿
3. 输入信号频率不宜过高: 建议 < 500kHz (至少2个计数周期)
4. 输入信号频率不宜过低: 建议 > 15Hz (周期不超过65ms)
5. 修改TIM_No_TEST宏后需重新编译才能切换TIM通道
6. TIM4的PWM输出和TIM1的捕获输入使用不同的TIM模块，互不冲突
7. 中断优先级设置为最低(0x0F/0x0F)，多中断场景可按需调整
8. 如需捕获中心对齐模式的PWM，需修改TIM_Configuration中计数模式
