================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了通用定时器(TIM)的刹车(Braking)功能。
当TIM检测到刹车事件时，触发刹车中断(Break)，
自动关闭PWM输出通道，用于电机控制中的紧急停止保护。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化、GPIO初始化、TIM初始化(含刹车配置)、NVIC初始化
3. TIM配置PWM输出和刹车输入引脚
4. 施加刹车信号(外部引脚电平变化)触发刹车事件
5. 在TIM_IRQHandler中断中检测刹车标志并处理

================================================================================
注意事项：
1. 刹车功能用于电机控制、电源管理中的故障保护
2. 刹车事件可自动将PWM输出引脚置于安全状态(高阻/低电平)
3. 刹车信号通常来自比较器、外部故障检测电路等

================================================================================
