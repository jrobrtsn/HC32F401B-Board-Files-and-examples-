================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了此样例演示了ADC配合DMA进行多序列多通道自动采样传输。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
*              1. 编译并下载程序
*              2. 系统初始化
*              3. ADC初始化 		其中序列0触发源为TIM9 CC1 序列1触发源为TIM9 CC2
*              4. DMA与TIM9初始化 	其中TIM9 CC1/CC2通道输出PWM波，上升沿依次触发ADC 序列0/1启动转换
*              5. 等待DMA转换完成中断置起标志位，在主循环中计算全部通道电压值


================================================================================
*	注意事项： 
*	
*	禁止4个序列的触发源为同一触发源同时开启转换
================================================================================
