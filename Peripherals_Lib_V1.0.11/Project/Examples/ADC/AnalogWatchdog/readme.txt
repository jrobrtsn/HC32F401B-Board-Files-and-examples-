================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了ADC的模拟看门狗(Analog Watchdog)功能，对AN1(PA9)通道进行电压监控，
当电压低于设定的下限阈值时触发模拟看门狗中断(AWDTL)，实现电压异常检测。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化与ADC初始化（含模拟看门狗配置）
3. ADC的序列1 依次采集通道 AN0(PA8) 、AN1(PA9) 、AN2(PA10) 的电压值
4. 模拟看门狗监控AN1通道，上限阈值0xA00，下限阈值0x300（12位补码格式，BIT11为符号位）
5. 当AN1通道的ADC转换值低于下限阈值时，触发AWDTL中断
6. 在中断中读取各通道转换值，并清除模拟看门狗中断标志

================================================================================
注意事项：
1. 模拟看门狗监控通道为AN1(PA9)，可将该引脚连接可调电压源进行测试
2. ADC为12位精度(含符号位BIT11)，有效分辨率11位，ADC转换值范围0~2047
3. 阈值寄存器为12位补码格式，0xA00=2560, 0x300=768
4. 本例仅演示下限阈值(AWDTL)中断，上限阈值(AWDTH)中断用法类似
