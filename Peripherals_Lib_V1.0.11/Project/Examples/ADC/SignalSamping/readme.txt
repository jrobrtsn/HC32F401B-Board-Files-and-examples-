================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了ADC的序列1 对3个通道切换采样。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化与ADC初始化
3. ADC的序列1 依次采集通道 AN0(PA8) 、AN1(PA9) 、AN2(PA10) 的电压值
4. 等待序列1 转换完成，进入转换完成中断，读取并转换电压值
5. 退出中断，再次软件触发ADC序列1 通道采样。

================================================================================
注意事项：
	禁止4个序列的触发源为同一触发源同时开启转换
================================================================================
