================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了ADC配合DMA实现多通道自动数据传输。ADC序列1每完成一个通道
(AN0/AN1/AN2)转换后，DMA自动将转换结果搬运到内存数组ADC_DAT[]中，无需CPU干预。
DMA完成一轮3个数据的搬运后触发传输完成中断，在中断中再次软件触发ADC转换，
形成"ADC转换→DMA搬运→DMA中断→再次触发"的自动循环流水线。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. 系统初始化、GPIO初始化、DMA初始化、ADC初始化
3. ADC的序列1 依次采集通道 AN0(PA8) 、AN1(PA9) 、AN2(PA10) 的电压值
4. 每完成一个通道转换，DMA自动将12位ADC数据搬运到ADC_DAT[]数组
5. DMA完成3个数据搬运后触发传输完成中断(TC)
6. 在DMA中断中清除标志位，并再次软件触发ADC，形成循环采集

================================================================================
注意事项：
1. DMA配置为循环模式(Circular)，写满后自动回到数组起始地址
2. ADC_DAT[]数组长度为3，对应Channel0/Channel1/Channel2，数据类型为uint16_t
3. DMA通道为DMA1_Stream0_Channel0，数据宽度为半字(16位)
4. 在调试器中可实时观察ADC_DAT[]数组值的变化
