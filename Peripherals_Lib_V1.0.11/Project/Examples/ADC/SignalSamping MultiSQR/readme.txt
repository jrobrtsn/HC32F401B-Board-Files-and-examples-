================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了ADC的序列1 对3个通道切换采样。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
*              1. 编译并下载程序
*              2. 系统初始化
*              3. ADC序列0初始化并软件触发
*              4. 等待ADC序列0转换完成
*              5. 在ADC序列0完成中断切换配置序列1，关闭序列0
*              6. 等待ADC序列1转换完成后，在主循环中计算全部通道电压值
*              7. 切换配置序列0，关闭序列1，构成扫描多序列循环

================================================================================
注意事项：
	禁止4个序列的触发源为同一触发源同时开启转换

================================================================================
