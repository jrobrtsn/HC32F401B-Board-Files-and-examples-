================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示了外部中断(EXTI)的基本使用。PA10配置为EXTI Line10下降沿触发中断（内部上拉），
当PA10检测到下降沿时触发EXTI15_10中断服务函数，在中断中翻转PA9电平作为事件响应指示。
主循环中PA8持续翻转，作为程序运行状态指示灯。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
1. 编译并下载程序；
2. PA8持续翻转，指示程序正常运行
3. 将PA10引脚接地（产生下降沿），触发EXTI中断
4. 观察PA9引脚电平翻转（每次下降沿翻转一次）
5. 多次触发可观察到PA9持续翻转

================================================================================
注意事项：
1. PA10配置为内部上拉，默认高电平，接地时产生下降沿触发中断
2. EXTI Line10~Line15共用EXTI15_10_IRQHandler中断向量，若同时使用多条Line需在中断内逐一判断标志位
3. 使用EXTI前必须使能SYSCFG时钟（RCC_APB2Periph_SYSCFG）
