================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示FLASH读写操作。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
实验步骤：
1. 编译下载程序并进入仿真模式；
2. 在GPIO_ToggleBits处打一个断点，点击全速运行；
3. 在watch窗口查看buf变量，就是写入后读取的值。
