================================================================================
                                样例使用说明

================================================================================
功能描述：
此样例演示芯片CANFD环回模式下数据的发送与接收

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
使用步骤：
*              1. 编译并下载程序
*              2. 系统/GPIO初始化 
*              3. CANFD/中断初始化
*              4. 填充数据后发送
*              5. 待发送完成中断响应读取数据


================================================================================
注意事项：
*	由于CANFD模块时钟设计有误，使用CANFD时时钟源 ≤ 48MHz  且需保证 HCLK = PCLK  
*	所以需要使用CANFD模块时，系统最高频率为96MHz 例程中SYS_Configuration函数已配置好，直接调用即可
*
*	通过修改宏定义 TEST_BUFFER_FIFO 变更发送与接受模式
*	0 - BUFFER 
*	1 - FIFO
================================================================================
