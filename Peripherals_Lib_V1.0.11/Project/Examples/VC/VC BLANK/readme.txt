================================================================================
                                示例使用说明

================================================================================
工程概述：
本示例演示了VC(电压比较器)模块的输出消隐(BLANK)功能。
VC消隐窗口由TIM1的OC1REFC上升沿触发(本例用CH1)，在消隐期间屏蔽
特定时间段的干扰(如PWM开关噪声)，提高比较器输出信号的可靠性。

工作原理：
  TIM1产生PWM信号的同时，其比较输出参考信号(OC1REFC)作为VC消隐触发源。
  当消隐信号有效时，VC输出被强制锁定为预设的消隐极性电平，
  此时即使输入信号有毛刺或干扰也不会触发误中断/误比较。
  消隐窗口外VC正常工作，实现精准的电压比较。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
硬件连接：
  反向输入:  PC8(VC0_INN_CH0)      = 参考电压
  正向输入:  PC9(VC0_INP_CH1)      = 被测信号(如含开关噪声的采样电压)
  比较输出:  PA3(VC0_OUT)          = 比较结果(示波器观察消隐效果)
  TIM1 CH1:  PC5(TIM1_CH1, AF1)   = PWM输出(可接示波器与VC_OUT对比)
  TIM1 CH2:  PC7(TIM1_CH2, AF1)   = PWM输出(第二路)
