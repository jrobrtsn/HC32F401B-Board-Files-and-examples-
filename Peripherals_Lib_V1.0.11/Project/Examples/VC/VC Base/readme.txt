================================================================================
                                示例使用说明

================================================================================
工程概述：
本示例演示了VC(电压比较器, Voltage Comparator)模块的基础使用。
初始化VC0比较器(INN_CH0: PC8, INP_CH1: PC9)，使能上升沿中断，
当正向输入端电压(PC9)超过反向输入端电压(PC8)时触发中断。

================================================================================
MDK版本： 5.36.0.0
IAR版本： 8.20.2

================================================================================
硬件连接：
  反向输入: PC8(VC0_INN_CH0) = 参考电压(如GND或电阻分压)
  正向输入: PC9(VC0_INP_CH1) = 被测电压信号
  比较输出: PA3(VC0_OUT)     = 比较结果输出(可选接示波器观察)

================================================================================
使用步骤：
1. 编译并烧录程序
2. 系统初始化 → GPIO初始化 → VC0初始化 → NVIC初始化
3. VC0比较器开始工作，比较INP和INN的输入电压
4. 当VINP > VINN时，触发VC0_IRQHandler上升沿中断
5. 可在中断函数内设断点观察比较器触发情况
6. 改变输入电压，观察中断是否按预期触发

================================================================================
注意事项：
1. VC是模拟电压比较器，内部无ADC转换，输出为数字电平
2. 迟滞功能(Hysteresis)可提高抗干扰能力，防止输入信号在阈值附近抖动
3. 数字滤波功能可用于滤除窄脉冲干扰(需配置滤波时钟和预分频)
4. 响应速度选High时传播延迟约几十ns，选Low时功耗更低
5. 模拟输入管脚需配置为GPIO_Mode_AN(模拟模式)，不需要上下拉
6. 可使用内部基准电压(1.2V/VDDA三分一等)作为参考，无需外部电压源

================================================================================
